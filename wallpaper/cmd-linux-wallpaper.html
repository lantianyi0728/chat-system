命令速查壁纸

Linux · Windows CMD · Git · 快捷键　|　白字为命令，绿字为说明

Linux · 文件与目录
pwd 显示当前所在目录
ls -la 列出全部文件(含隐藏)及详情
cd ~ 回到用户主目录
cd .. 返回上一级目录
cd /path 切换到指定目录
mkdir dir 新建文件夹
touch a.txt 新建空文件
cp 源 目标 复制文件或目录
mv 旧 新 移动或重命名
rm 文件 删除文件
rm -rf dir 强制删除文件夹
cat 文件 查看文件全部内容
less 文件 分页查看(空格翻页)
head -n 5 f 查看文件前 5 行
tail -f 文件 实时追踪文件末尾
ln -s 源 链接 创建软链接
Linux · 系统 / 进程 / 网络
ps aux 查看所有进程
top 实时监控资源占用
kill 1234 结束指定 PID 进程
kill -9 1234 强制结束进程
df -h 查看磁盘剩余空间
du -sh dir 统计目录占用大小
free -m 查看内存使用情况
uname -a 查看内核与系统信息
ifconfig 查看网卡 IP 地址
ping 主机 测试网络连通性
wget 网址 下载网络文件
curl -O 网址 下载并显示进度
netstat -tunlp 查看监听端口
chmod 755 文件 修改文件权限
sudo 命令 以管理员身份执行
uptime 查看运行时长与负载
CMD · Windows 常用
echo %cd% 显示当前目录
cd 切换目录
cd .. 返回上一级
dir 列出当前目录文件
md 名字 新建文件夹
type nul > a.txt 新建空文件
copy 源 目标 复制文件
move 旧 新 移动 / 重命名
del 文件 删除文件
rmdir /s dir 删除文件夹
type 文件 查看文本文件内容
cls 清屏
systeminfo 查看系统信息
shutdown /s 关机
shutdown /r 重启
where 名字 查找命令路径
CMD · 进程 / 网络 / 磁盘
tasklist 查看运行中的进程
taskkill /pid 1234 结束指定进程
taskmgr 打开任务管理器
ipconfig 查看网络配置
ipconfig /flushdns 刷新 DNS 缓存
ping 主机 测试网络连通
tracert 主机 追踪路由路径
netstat -an 查看所有连接
chkdsk 检查磁盘错误
wmic logicaldisk 查看磁盘空间
sfc /scannow 修复系统文件
compact /c dir 压缩目录
powershell 启动 PowerShell
help 查看命令帮助
ver 查看系统版本
assoc 查看文件类型关联
Git · 版本控制
git init 初始化仓库
git clone 网址 克隆远程仓库
git add . 暂存所有改动
git commit -m "x" 提交到本地
git status 查看当前状态
git diff 查看具体改动
git log --oneline 查看提交历史
git branch 查看分支列表
git checkout -b x 新建并切换分支
git merge x 合并指定分支
git pull 拉取并合并更新
git push 推送到远程
git remote -v 查看远程地址
git reset --hard 回退到上一版本
git stash 暂存未提交改动
git clone -b x 网址 克隆指定分支
快捷键 · 通用
Ctrl + C 复制选中内容
Ctrl + V 粘贴
Ctrl + X 剪切
Ctrl + Z 撤销
Ctrl + A 全选
Ctrl + S 保存文件
Ctrl + F 查找内容
Tab 命令自动补全
↑ / ↓ 浏览历史命令
Alt + Tab 切换窗口
Win + D 显示桌面
Win + E 打开文件管理器
Win + R 打开运行窗口
Ctrl + L 终端清屏(Linux)
Ctrl + R 搜索历史命令
Win + L 锁定计算机
提示：Linux 区分大小写；CMD 参数常用 /（如 shutdown /s）；Git 命令需在仓库目录内使用
