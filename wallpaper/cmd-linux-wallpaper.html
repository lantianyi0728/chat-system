Linux vs CMD 命令速查

左：Linux 终端　·　右：Windows CMD　|　白字为命令，绿字为说明

Linux 常用命令
pwd 显示当前所在目录
ls -la 列出全部文件(含隐藏)及详情
ls -lh 以易读大小列出文件
cd ~ 回到用户主目录
cd .. 返回上一级目录
cd /path 切换到指定目录
mkdir dir 新建文件夹
touch a.txt 新建空文件
cp 源 目标 复制文件或目录
mv 旧 新 移动或重命名
rm 文件 删除文件
rm -rf dir 强制删除文件夹
cat 文件 查看文件全部内容
less 文件 分页查看(空格翻页)
head -n 5 f 查看文件前 5 行
tail -f 文件 实时追踪文件末尾
grep "词" 文件 在文件中搜索文字
find . -name "*.txt" 按名称查找文件
chmod 755 文件 修改文件权限
tar -czf x.tgz dir 压缩为 tar.gz
tar -xzf x.tgz 解压 tar.gz
wget 网址 下载网络文件
curl -O 网址 下载并显示进度
ps aux 查看所有进程
top 实时监控资源占用
kill 1234 结束指定 PID 进程
kill -9 1234 强制结束进程
df -h 查看磁盘剩余空间
du -sh dir 统计目录占用大小
free -m 查看内存使用情况
uname -a 查看内核与系统信息
ifconfig 查看网卡 IP 地址
ping 主机 测试网络连通性
netstat -tunlp 查看监听端口
sudo 命令 以管理员身份执行
shutdown -h now 关机
Windows CMD 常用命令
echo %cd% 显示当前目录
cd 切换目录
cd .. 返回上一级
dir 列出当前目录文件
dir /a 含隐藏文件一起列出
md 名字 新建文件夹
rd 名字 删除空文件夹
type nul > a.txt 新建空文件
copy 源 目标 复制文件
move 旧 新 移动 / 重命名
del 文件 删除文件
rmdir /s dir 删除文件夹
ren 旧 新 重命名文件
type 文件 查看文本文件内容
more 文件 分页查看文件
findstr "词" 文件 在文件中搜索文字
cls 清屏
tasklist 查看运行中的进程
taskkill /pid 1234 结束指定进程
taskmgr 打开任务管理器
ipconfig 查看网络配置
ipconfig /flushdns 刷新 DNS 缓存
ping 主机 测试网络连通
tracert 主机 追踪路由路径
netstat -an 查看所有连接
systeminfo 查看系统信息
ver 查看系统版本
chkdsk 检查磁盘错误
wmic logicaldisk 查看磁盘空间
sfc /scannow 修复系统文件
compact /c dir 压缩目录
powershell 启动 PowerShell
where 名字 查找命令路径
help 查看命令帮助
shutdown /s 关机
shutdown /r 重启
提示：Linux 区分大小写；CMD 参数常用 /（如 shutdown /s）
